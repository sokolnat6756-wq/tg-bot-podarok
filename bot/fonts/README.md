# Шрифты для открыток (SIL Open Font License 1.1)

| Файл | Семейство | Назначение |
|---|---|---|
| `GreatVibes-Regular.ttf` | Great Vibes | Имя и короткий акцент у взрослых (люксовая каллиграфия) |
| `PlayfairDisplay-Italic.ttf` | Playfair Display Italic | Строка повода у взрослых |
| `PlayfairDisplay.ttf` | Playfair Display | Текст пожелания у взрослых |
| `Nunito.ttf` | Nunito (variable) | Имя, повод и пожелание детям и подросткам |

Дополнительно в папке могут оставаться старые OFL-файлы (`Comforter`, `Cormorant`, `Manrope`, `Marck Script`) — запасные.

Лицензии: `OFL-*.txt` рядом с файлами. Источник: [Google Fonts](https://github.com/google/fonts).
