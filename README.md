# Подбери идеальный подарок

Telegram-бот, который за несколько вопросов с кнопками подбирает **3 идеи подарков** с пояснениями — в рамках бюджета и возраста. Без платных ИИ-сервисов и без регистрации пользователей.

## Что умеет бот

1. Команда `/start` — приветствие и кнопка «Подобрать подарок»
2. Опрос кнопками: кому, пол, возраст, повод, бюджет, интересы
3. Три рекомендации с ценой и кратким «почему подходит»
4. Кнопка «Другие варианты» — новые идеи без повторов
5. У каждого пользователя своя сессия (два человека не мешают друг другу)

## Быстрый старт на компьютере

### 1. Создайте бота в Telegram

1. Откройте [@BotFather](https://t.me/BotFather)
2. Команда `/newbot` — придумайте имя и username
3. Скопируйте токен (выглядит как `123456:ABC...`)

### 2. Настройте проект

```bash
python -m venv .venv
```

Windows (PowerShell):

```powershell
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
copy .env.example .env
```

Откройте файл `.env` и вставьте токен:

```
BOT_TOKEN=ваш_токен_от_BotFather
```

Файл `.env` уже в `.gitignore` — токен не попадёт в Git.

### 3. Запустите

```powershell
python run.py
```

Напишите боту `/start` в Telegram.

## Проверка без токена

Автопроверка логики подбора (бюджет, возраст, без повторов, изоляция пользователей):

```powershell
python tests\check_readiness.py
```

Ожидаемый ответ: `OK: бюджет/возраст, без повторов, изоляция пользователей — пройдено.`

## Деплой на Timeweb Cloud App Platform (Docker)

Проект уже подготовлен под сборку через `Dockerfile`. Режим работы — **polling** (бот сам опрашивает Telegram).

1. Залейте репозиторий на GitHub **без** файла `.env` (он в `.gitignore`)
2. В [Timeweb Cloud](https://timeweb.cloud/) создайте приложение App Platform из этого репозитория / Dockerfile
3. В переменных окружения приложения добавьте секрет **`BOT_TOKEN`** (значение — токен от BotFather)
4. Запустите приложение: контейнер выполнит `python -u run.py`

Отдельный веб-порт и webhook не нужны. Важно: одновременно должна работать **только одна** копия бота с этим токеном.

### Данные при перезапуске

Сессии пользователей хранятся **только в памяти процесса**, базы данных нет. После перезапуска или нового деплоя незавершённые опросы сбрасываются — пользователю достаточно снова нажать «Подобрать подарок». Для постоянного хранения понадобилась бы отдельная БД или диск (в этой версии не используются).

## Структура проекта

```
BRIEF.md                 — исходное ТЗ
README.md                — эта инструкция
Dockerfile               — сборка для Timeweb App Platform
.dockerignore            — что не попадает в образ
requirements.txt         — зависимости Python
.env.example             — образец переменных (без секретов)
run.py                   — запуск бота
bot/
  main.py                — точка входа
  handlers.py            — команды и кнопки
  keyboards.py           — клавиатуры
  gifts.py               — каталог и подбор подарков
  session.py             — сессии пользователей
  config.py              — чтение BOT_TOKEN
tests/
  check_readiness.py     — проверка критериев готовности
```

## Важно про секреты

- Не публикуйте `.env` и токен в чатах, GitHub и скриншотах
- Если токен случайно засветился — отзовите его в BotFather (`/revoke`) и создайте новый

## Что проверить вручную в Telegram

- [ ] `/start` показывает приветствие и кнопку
- [ ] Все шаги опроса открываются кнопками
- [ ] Три идеи соответствуют бюджету и возрасту
- [ ] «Другие варианты» выдаёт новые идеи
- [ ] Два разных аккаунта проходят опрос независимо
